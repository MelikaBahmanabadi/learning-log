Q:: مقادیر falsy؟

Q:: جابجایی دو متغیر؟

Q:: ایندکس + مقدار در حلقه؟

Q:: پارامترهای keyword-only؟

Q:: فرق list و tuple؟
A:: لیست mutable، تاپل immutable. تاپل کم‌مصرف، hashable، record ثابت. لیست over-allocation داره.
--
Q:: Slicing [start:stop:step]؟
A:: start شامل، stop غیرشامل، step = گام. step منفی برعکس می‌کنه. هر سه اختیاری.
--
Q:: seq[::-1]؟
A:: دنباله رو برعکس می‌کنه.
--
Q:: مقدار دادن به slice؟
A:: `list[2:5] = [100,200]` جایگزین می‌کنه. طول می‌تونه تغییر کنه. step-slice نیاز به طول مساوی داره.
--
Q:: درج در i با slice؟
A:: `list[i:i] = [item]`
--
Q:: شیء slice؟
A:: `slice(start, stop, step)` — ضمنی از `seq[1:5:2]`. می‌شه نام‌گذاری و استفاده مجدد کرد.
--
Q:: پیچیدگی list.append()؟
A:: O(1) amortized.
--
Q:: پیچیدگی list.pop(0)؟
A:: O(n) — همه عناصر جابجا می‌شوند. از `deque.popleft()` برای O(1).
--
Q:: namedtuple؟
A:: `namedtuple("Point", ["x","y"])` — زیرکلاس tuple با فیلدهای نام‌دار. Immutable، hashable، کم‌مصرف.
--
Q:: array.array کی بهتر از list؟
A:: داده‌های عددی همگن بزرگ — type-safe، کم‌مصرف، I/O باینری سریع.
--
Q:: deque نسبت به list؟
A:: deque O(1) append/popleft در دو سمت. list O(n) pop(0). برای صف و sliding window.
--
Q:: bisect.insort؟
A:: جستجوی دودویی (O(log n))، درج (O(n) شیفت). لیست مرتب می‌مونه.
--
Q:: bisect_left vs bisect؟
A:: bisect_left = قبل از مقادیر مساوی. bisect = بعد از مقادیر مساوی.
--
Q:: deque محدود؟
A:: `deque(maxlen=5)` — وقتی پر شد، آیتم سمت مخالف حذف می‌شه.
--
Q:: پروتکل sequence؟
A:: `__len__` + `__getitem__` — فعال‌سازی slicing، iteration، `in`، `reversed()`.
--
Q:: struct.pack؟
A:: بسته‌بندی به باینری: `struct.pack('>i4sh', 7, b'spam', 8)`.
--
Q:: memoryview؟
A:: دسترسی zero-copy به بافر — مشاهده/تغییر بایت‌ها بدون کپی.
--
Q:: tuple packing/unpacking؟
A:: Pack: `t = 1, 2, 3`. Unpack: `a, b, c = t`.
--
Q:: namedtuple سریالایز؟
A:: متد `._asdict()`. همان حافظه تاپل معمولی.
--
Q:: تغییر عنصر tuple؟
A:: TypeError — immutable. ولی اشیاء mutable داخل tuple می‌تونن تغییر کنن.
--
Q:: برعکس کردن درجا vs کپی برعکس؟
A:: `list.reverse()` درجا. `reversed(seq)` iterator. `seq[::-1]` لیست جدید.
--
Q:: seq[::2]؟
A:: هر عنصر دوم.
--
Q:: تقسیم دنباله در نقطه؟
A:: `head, tail = seq[:i], seq[i:]`
--
Q:: Ellipsis (...) در پایتون؟
A:: "همه ابعاد قبلی" — در NumPy و کانتینرهای سفارشی.
--
Q:: دنباله container vs flat؟
A:: container (list, tuple, deque) = reference، انواع مختلف. flat (str, bytes, array) = مقدار مستقیم، یک نوع.
--
Q:: deque برای صف؟
A:: FIFO: deque O(1) popleft. list O(n) pop(0). thread-safe: `queue.Queue`.
--
Q:: rolling window با zip؟
A:: `list(zip(*(seq[i:] for i in range(n))))` — تاپل‌های لغزنده nتایی.
