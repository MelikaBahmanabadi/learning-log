# Python Flashcards — EN (Anki Import)

Q:: Pythonic file open?
A:: `with open(path) as fh:`
--
Q:: EAFP vs LBYL?
A:: EAFP = try/except (Pythonic). LBYL = if checks.
--
Q:: Create venv?
A:: `python -m venv .venv && source .venv/bin/activate`
--
Q:: Modern project config?
A:: `pyproject.toml` (PEP 517/518/621).
--
Q:: Falsy values?
A:: `0`, `0.0`, `""`, `[]`, `{}`, `set()`, `None`, `False`.
--
Q:: Swap two variables?
A:: `a, b = b, a`
--
Q:: Index + value in loop?
A:: `for i, v in enumerate(seq):`
--
Q:: Iterate two sequences?
A:: `for a, b in zip(xs, ys):`
--
Q:: Walrus operator?
A:: `:=` — assign and use in expression.
--
Q:: Default mutable arg gotcha?
A:: `def f(lst=[])` shared. Use `def f(lst=None)`.
--
Q:: Positional-only params?
A:: Params before `/` can't be keyword: `def div(a, b, /):`
--
Q:: Keyword-only params?
A:: Params after `*` must be keyword: `def f(*, kw):`
--
Q:: `if __name__ == "__main__"`?
A:: Run only when executed directly.
--
Q:: PEP 8 function naming?
A:: `snake_case`
--
Q:: PEP 8 class naming?
A:: `PascalCase`
--
Q:: LEGB rule?
A:: Local → Enclosing → Global → Built-in.
--
Q:: `is` vs `==`?
A:: `is` = identity; `==` = value equality.
--
Q:: List comprehension?
A:: `[x**2 for x in range(10) if x % 2 == 0]`
--
Q:: Dict comprehension?
A:: `{x: x**2 for x in range(5)}`
--
Q:: Set comprehension?
A:: `{x for x in range(20) if x % 2 == 0}`
--
Q:: Flatten nested list?
A:: `[x for row in matrix for x in row]`
--
Q:: `for` loop `else` clause?
A:: Runs if loop completed without `break`.
--
Q:: Iterate dict kv pairs?
A:: `for k, v in dict.items():`
--
Q:: f-string 2 decimal places?
A:: `f"{value:.2f}"`
--
Q:: pathlib join paths?
A:: `Path("folder") / "sub" / "file.txt"`
--
Q:: Copy a list?
A:: `lst.copy()` or `lst[:]`
--
Q:: Dict merge (Python 3.9+)?
A:: `dict1 | dict2`
--
Q:: Safe dict get with default?
A:: `dict.get("key", "default")`
